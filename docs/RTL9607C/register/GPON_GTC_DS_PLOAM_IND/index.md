# RTL9607C register: GPON_GTC_DS_PLOAM_IND

## Details

*Name* GPON_GTC_DS_PLOAM_IND

*Offset* 0x701080

*Feature* [GTC_DOWNSTREAM](../../feature/GTC_DOWNSTREAM)

## Description

Downstream PLOAM message indication

## Fields


|Bit(s)|Field Name|Description|
| :--- | :--- | :--- |
|31:6|RESERVED||
|5|PLM_BUF_EMPTY|Indicate the PLOAMd buffer is empty.|
|4|PLM_BUF_FULL|Indicate the PLOAMd buffer is full.|
|3:1|RESERVED||
|0|PLM_DEQ|Write 0x1 to refresh PLOAM_RDATA.<br>PLOAMd reading is triggered by interrupt generated by PLM_BUF_REQ, then follows this procedure:<br>1. Read PLM_BUF_EMTPY, if PLM_BUF_EMPTY = 0, goto step 2; else exit;<br>2. Read PLOAM_RDATA for 7 times<br>3. Write 0 then 1 to PLM_DEQ, to clear the recently read message buffer block<br>4. Goto step 1, to check once again|
