# RTL9607C register: CPU_HASH_PORT_CTRL

## Details

*Name* CPU_HASH_PORT_CTRL

*Offset* 0x11020

*Feature* [MAC_CONTROL](../../feature/MAC_CONTROL)

*Bit Offset:* 1

*Array Range:* 0-15

## Description

CPU Hash port control register
Only relevant to ports on 9 and 10 i.e CPU ports.

|Bit(s)|Field Name|Description|
| :--- | :--- | :--- |
