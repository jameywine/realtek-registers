# RTL9607C register: PISO_EXT

## Details

*Name* PISO_EXT

*Offset* 0x2702C

*Feature* [PORT_ISOLATION](../../feature/PORT_ISOLATION)

*Bit Offset:* 29

*Array Range:* 0-17

## Description

Port isolation configuration that each extension port can specify a port list to communicate
with.

## Fields


|Bit(s)|Field Name|Description|
| :--- | :--- | :--- |
|28:0|PORTMASK|The destination portmask of ingress port|
