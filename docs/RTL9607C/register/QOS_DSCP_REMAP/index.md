# RTL9607C register: QOS_DSCP_REMAP

## Details

*Name* QOS_DSCP_REMAP

*Offset* 0x1C2B0

*Feature* [INGRESS_PRIORITY_DECISION](../../feature/INGRESS_PRIORITY_DECISION)

*Bit Offset:* 3

*Array Range:* 0-63

## Description

Specify a 3-bit internal priority for a DSCP value.

|Bit(s)|Field Name|Description|
| :--- | :--- | :--- |
